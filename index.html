The kit

Seven components, one wind.

Each one is a custom element with no dependencies. Drop in the script and write the tag. Every figure below is live: try the pointer, the keyboard, and the motion switch at the top.

How it works

One model, every motion.

The painting is the model

model.mjs measures the panorama: six Lamb–Oseen vortices, a solid core that blends into a 1/r swirl and fades with a Gaussian, placed on the great swirl, its lower lobe, the right swirl, the tight curl, the moon's halo and the left edge. It also holds ten stars, the moon, and a river of cloud that rises to the right. The same field exists once in JS and once in GLSL.

Pixel art by construction

Every component draws into a canvas a few times smaller than its box. The browser scales it up with crisp pixels, and every colour snaps to one 8-tone ramp sampled from the image, from cypress ink to star gold, with a 4×4 ordered dither. The shader and the 2D components can't drift apart in look.

Calm, true motion

Time-based steps with dt capped at 1/30 s. Pointers set targets that parts follow with exponential easing. Real springs where things are springy (the cypress), critically damped settles where they should arrive cleanly (scatter, swell), and attack/decay envelopes for one-off events (flares, ripples).

Polite by default

Each component stops when it scrolls offscreen or settles, and under reduced motion it goes to one still frame that still responds to input. An idle tour starts after 1.4 s and yields to the reader. Each element is focusable, has keyboard controls, and keeps a live readout in aria-valuetext and a readout event.

Techniques adapted from Anatomy, a skill for crafted interactive figures: one pure model driving every number, framed cards with a live readout, envelopes that never pop, idle tours, and verifying by screenshot.

Install

Use it as a skill, or as tags.

As an agent skill

It works with skills.sh, so your agent learns the palette, the model and the motion rules, and can build new Starry Night animations with the kit.

npx skills add Khalidabdi1/Starry-Night

Then ask: “make a Starry Night loading screen for my app”.

As web components

Copy skills/starry-night/kit/ into your site. No build step, no dependencies.

<script type="module"
  src="kit/index.mjs"></script>

<starry-sky></starry-sky>

In React or Next.js

Typed wrappers that load the elements on the client only.

import { StarrySky } from
  "./kit/react/starry-night";

<StarrySky speed={1.2}
  onReadout={(t) => …} />
